# Life Lab · 高性价比人生决策实验室

一个零注册、手机优先、纯静态的中文交互决策实验室。选择生活情景、调整两个参数，观察在相同人物基线下现金与时间的变化，以及教学性八维 LVI 综合得分。

## 使用

直接打开仓库根目录的 **index.html**，理论与模型、原始研究全文已内置，脱离网络也能切换（外部统计来源需要联网）。静态网站可部署到 GitHub Pages。

## 9个案例

原始研究报告：搬家换时间、升职加薪、自由职业。
本站教学案例：家务外包、缩短工作周、进修投入。
参照 [《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter) 原始条目新增：关闭自动续费（第5节第1条）、减少低效会议（第4节第6条）、保证睡眠（第3节第3条）。

**所有后六个案例的量化评分均为本站教学假设。** 国家统计局数据仅作收入与时间的社会参照，不是 LVI 的校准标准，评分不预测个人健康或真实幸福感。高风险决定必须另行审查法律、医疗、必要支出及照护底线。

## 文件

- `index.html`：可直接运行的完整单文件版本。
- `理论与模型.html`、`研究全文.html`：可独立打开的阅读页面。
- `assets/`：计算模型、交互逻辑、样式源码。
- `data/official_statistics.json`：统计数字、年份、总体与来源。
- `content/原始研究报告.md`：研究原文。
- `ATTRIBUTION.md`：原指南 CC BY 4.0 来源、改编范围与独立评分声明。

## 发布

仓库同步后如需公开网页地址：在 `Settings → Pages` 中选择 `Deploy from a branch`，`main` 分支的 `/ (root)`。

本项目只用于教育性情景比较，不提供个体投资、医疗或法律结论。
